## 기준 (사용자 결정 2026-11-12)

- 기간 12/1(화) ~ **3/31(수)** (2/28에서 연장), 주말·12/25·1/1·설 2/5·대체 2/8(추정)·3/1 제외, **12/31은 근무일**
- 투입: 김태균·이태성 12/1, 최성민 12/7(12월 2째 주). 휴가는 이태성 12/14~12/25만 반영
- 개발일수: 난이도 1~2 → 1일, 3~4 → 2일, 5~7 → 3일, 8~10 → 5일. 미정/빈칸은 담당자 평균 난이도(반올림)
- 순서: 264xxx·266xxx 먼저(그 안에서 쉬운 것 먼저), 나머지 표 순서
- **개발 담당자는 사진 원본 그대로**(추후 담당자만 수정 예정, 사용자 결정 2026-11-12). 납기 날짜는 이관안 기준으로 산정한 값을 유지:
  원 배정대로면 이태성 84일 > 가용 73일이라 13개 화면(김태균 8·최성민 5)을 그 담당자 일정에 넣어 계산 → 엑셀 '일정 산정 담당자(이관안)' 열
- 개발 시작일 = 산정 담당자가 시작하는 날, 소요일 = 시작~납기 평일 수(주말만 제외), 실작업일 = 공휴일·휴가까지 제외
- 퍼블 납기 = **개발 시작일** 7일 전, 디자인 납기 = **개발 시작일** 14일 전(주말·휴일이면 직전 근무일, 2026-11-12 변경)

## 원본 엑셀에 넣는 함수 (개발 시작일 → 퍼블·디자인 납기)

원본 시트에서 개발 시작일을 R열에 둔다고 가정(2행 기준, 아래로 채우기). 휴일 목록 없이 주말만 피합니다.

| 칸 | 함수 |
|---|---|
| O2 퍼블 납기 | `=IF(R2="","",WORKDAY(R2-7+1,-1))` |
| M2 디자인 납기 | `=IF(R2="","",WORKDAY(R2-14+1,-1))` |

`WORKDAY(X+1,-1)` = X가 평일이면 X, 주말이면 직전 금요일. 공휴일까지 피하려면 마지막 인수로 휴일 범위를 넣습니다(예: `WORKDAY(R2-7+1,-1,$Z$2:$Z$7)`).
- 260000(11/27)·264000(12/01)은 기존 납기 유지, 중복화면 269300~269304 제외
