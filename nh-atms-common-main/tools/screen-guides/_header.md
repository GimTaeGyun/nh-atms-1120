# 09. 화면 개발 가이드 — 처음부터 만들기 (화면별)

> 화면 하나를 **빈 상태에서 처음부터 만든다고 보고**, 무엇을 어떤 순서로 만드는지 화면마다 한 "부"로 정리한 문서입니다.
> - 새 화면을 개발할 때마다 이 문서 끝에 **제N부**를 이어 붙입니다. 쓰는 법·형식: [`92_화면개발가이드_작성법.md`](92_화면개발가이드_작성법.md).
> - 이 파일은 **생성물**입니다. 손으로 고치지 말고 `tools/screen-guides/` 의 본문(`<화면키>.md`)·명세(`<화면키>.json`)를 고친 뒤 `python3 -I tools/gen_screen_guide.py` 로 다시 만듭니다(부록 A·B 는 도구가 소스에서 만듦).
> - 부마다 같은 형식: §0 한눈에 · §1 DB 준비 · §2 빨간줄 없는 개발 순서 · §3 가져다 쓴 공통 모듈 · §4 화면(탭·팝업)별 설명 · §5 백엔드 요약 · §6 검사 · 부록 A(새 파일 전체 · 기존 파일 diff, §2 순서) · 부록 B(SHA-512).
