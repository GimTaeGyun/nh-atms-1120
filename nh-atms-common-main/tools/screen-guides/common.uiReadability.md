> 새 화면이 아니라 **공통 모양(UI/UX) 개선**입니다(2026-11-13). 현업 화면(자동화기기 종합관리시스템 '미가동 사유 관리' 사진)을 기준으로 글자 크기·색·검색필터·좌측 메뉴·상단 메뉴를 맞췄습니다.
> - **반입은 파일 단위 전체 교체**입니다(2026-11-13 사용자 결정 — 전체 소스가 아니라 바뀐 파일만, 다른 소스 영향 최소화). 부록 A 의 8개 파일을 **통째로 덮어쓰기**만 하면 됩니다(부분 수정 없음). 부록 B = SHA-512.
> - 화면 파일(권한관리·메뉴관리·공지사항 등)은 **하나도 바뀌지 않습니다** — 모든 화면이 공통 테마·틀을 쓰므로 함께 좋아집니다.
> - 경로 줄임: src/ = Frontend/nh-atms-web/src/

## 0. 한눈에 보기

- **비유**: 건물 안 안내판·표지판의 글씨를 키우고 진하게 칠한 것. 방(화면)은 그대로이고 공용 표지판(공통 테마·틀)만 바꿨습니다.
- 사용자 결정(2026-11-13)
  1. 고치는 범위 = **공통 모양 파일만**(테마 3개 + 틀 CSS 3개 + 헤더·좌측 메뉴 TSX 2개).
  2. 검색필터 = **현업 화면과 같게**: 라벨 배경 칸 없이 `• 라벨` + 입력칸, [조회]는 오른쪽 넓은 남색 버튼.
  3. 기준 = **본문·표·입력·좌측 메뉴 14px**, 보조 글자 최소 13px(배지·꼬리글만 12px), 흐린 글자도 흰 바탕 대비 4.5:1 이상. 색은 현업 화면 기준.
  4. 반입 = **바뀐 파일 전체본 + 목록·SHA-512**.

| 부분 | 전 | 후 |
|---|---|---|
| 입력칸·콤보·버튼 글자 | 12px(antd 컴팩트 모드가 기본보다 2px 줄임) | **14px**(컴팩트 모드 해제, 높이는 32px 로 직접 맞춤) |

## 4. 화면별 설명

### 4-1. 글자 크기 · 색 규칙 (새 화면도 이대로)

- 글자 크기: 본문·표·입력·버튼·좌측 메뉴 **14px**(`var(--fs)`), 보조 글자(안내·브레드크럼·마지막 업데이트) **13px**(`var(--fs-sm)`), 배지·꼬리글·오류 문구만 **12px**(`var(--fs-xs)`). 그보다 작은 글자는 아이콘·숫자 배지 외에 쓰지 않습니다.
- 글자색: 본문 `var(--text)`, 보조 `var(--text-secondary)`, 흐린 안내 `var(--text-muted)`(이보다 연한 회색은 쓰지 않음).
- 화면 코드에서 `style={{ fontSize: 11 }}`·연한 회색을 직접 쓰지 않습니다 — 위 변수·antd 기본을 씁니다.

### 4-2. 검색필터 (`global.css` `.search-panel`)

- 라벨 = `• 라벨`(검정 동그라미 + 14px 굵게, 최소 폭 88px, 배경 없음). 필수 칸은 동그라미가 빨강.
- [조회] 버튼 = 오른쪽 남색, 폭 160px·높이 34px. 입력칸 높이 32px.
- `SearchForm.tsx` 는 바꾸지 않았습니다(CSS 만).

### 4-3. 상단 메뉴 · 헤더 (`layout.css`, `AppHeader.tsx`)

- 1뎁스 메뉴 15px, 사이 얇은 세로줄, 선택 = 남색 굵은 글자 + 아래 3px 남색 줄(배경 없음).
- 오른쪽 = 화면 검색(높이 34px) + `☆ 즐겨찾기 ▾`(폭 150px, 즐겨찾기가 있으면 금색 별). 1280px 미만이면 '즐겨찾기' 글자를 숨기고 별·화살표만.

### 4-4. 좌측 메뉴 (`layout.css`, `SidePanel.tsx`)

- 맨 위 = 대메뉴 제목(16px 굵게, 아래 구분선). 즐겨찾기 상자는 헤더로 옮겼습니다.
- 중메뉴 폴더 = 14px 진한 회색 굵게 + 접기 화살표, 폴더 사이 구분선. 소메뉴 = 14px 검정, 선택 = 남색 채움 + 흰 굵은 글자.
- 아래 사용자 카드(이름 14px·소속 12px) + 환경설정은 그대로.

### 4-5. 표 · 탭바 · 화면 제목 (`global.css`, `layout.css`, `page.css`)

- 표: 14px, 머리글 굵고 진한 글자 + 연한 회청색 배경 + 칸 사이 세로줄, 행 높이 약 33px.
- 탭바: 탭 글자 14px, 선택 탭 = 흰 바탕 + 남색 굵은 글자 + 위쪽 남색 줄.
- 화면 제목 20px + 왼쪽 남색 막대, 브레드크럼 13px(마지막 칸 검정), 부제·마지막 업데이트 13px.
