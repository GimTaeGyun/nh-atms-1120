## 0. 한눈에 보기

- **비유**: 지금까지는 사진을 원본 크기로 걸어 둬서, 보는 사람이 브라우저 확대/축소(Ctrl −)로 80% 로 줄여 봤습니다. 이제는 **사진 자체를 80% 크기로 다시 뽑았습니다** — 100% 로 열면 예전 80% 화면과 같습니다.
- 사용자 결정(2026-11-13)
  1. 크롬 80% 로 본 비율을 100% 기본으로. 방법 = **디자인 값 자체를 줄임**(배율 기능·환경설정 없음).
  2. 페이징 없는 표의 맨 아래가 잘 안 보임 → **표 전체 테두리 + 아래 '총 n건' 줄**.

| 부분 | 전 | 후 |
|---|---|---|
| 본문·표·입력 글자 | 14px | **11.2px** (`var(--fs)`) |
| 보조 글자 / 배지 | 13 / 12px | **10.4 / 9.6px** (`--fs-sm` / `--fs-xs`) |
| 입력·버튼 높이(보통 / 작은 / 큰) | 32 / 26 / 38px | **25.6 / 20.8 / 30.4px** |
| 머리줄 · 탭줄 · 아이콘 줄 · 사이드 패널 | 56 · 38 · 64 · 220px | **44.8 · 30.4 · 51.2 · 176px** |
| antd 여백·간격 | 4px 단위 | **3.2px 단위**(`sizeUnit`·`sizeStep`) |
| 화면 폭 기준(조회조건 줄 나눔 · 최소 폭 · 사이드 패널 자동 접힘) | 1280·1600 · 1050 · 1366px | **1024·1280 · 840 · 1093px** |
| 테두리 없는 표 | 바깥 선 없음 → 마지막 행 아래가 바탕과 섞임 | **바깥 테두리 상자** |
| 페이징 없는 표(메뉴관리·메뉴 권한·기기모델 등) | 아래 아무것도 없음 | **'총 n건'** 한 줄(페이징 있는 표의 왼쪽 글과 같은 자리·모양) |
| 편집 표 행 높이 | 약 35px(칸 안 폼 칸이 보통 크기) | **약 30px**(목록 표와 같음) |


## 4. 화면별 설명

### 4-1. 비율 (모든 화면)

- 글자·높이·여백·폭이 같은 비율(0.8)로 줄어서, 100% 배율에서 예전 80% 배율 화면과 같은 모양입니다.
- **앞으로 새 화면·CSS** 에서 크기를 쓸 때는 "예전 감각 값 × 0.8"(예: 여백 12px → 9.6px)로 쓰거나, TS 에서는 `sc(12)` 로 씁니다. 글자는 늘 `var(--fs)` 등 변수로.
- 이번에 손대지 않은 것(값이 화면 파일 안에 있음): 팝업 폭(예: 공지 팝업 `width={760}`)·표 칸 폭(`col('제목', 'subject', 360)`)·상세 표 라벨 폭. 표 칸은 화면 폭을 채우도록 늘어나서 차이가 거의 없고, 팝업은 예전 80% 때보다 조금 넓어 보입니다. 화면을 고칠 때 `sc(760)` 처럼 바꾸면 됩니다.

### 4-2. 표 끝 구분

- 테두리 없는 표(`DataGrid` 기본)도 바깥을 연한 테두리 상자로 감쌉니다 → 행이 적어도 마지막 행 아래 끝선이 보입니다.
- 페이징 없는 표(`clientPageSize={0}`, `EditableGrid`)는 아래에 '총 n건' 한 줄이 생깁니다. 페이징 있는 표의 '총 n건'과 같은 자리·모양입니다.
- 표가 남은 높이를 채울 때 이 줄 높이(위 여백 포함)를 빼고 계산합니다(`useFillHeight`) — 화면 스크롤이 생기지 않습니다.

### 4-3. 편집 표 행 높이 · 필수 라벨 (같은 날 추가)

- 편집 표(`EditableGrid` — 권한관리 메뉴 권한, 기기모델코드)는 칸 안 체크·입력·콤보를 **작은 크기(20.8px)** 로 그립니다(`Form size="small"` + 폼 칸 최소 높이 풀기). 행 높이가 약 35 → 30px 로 목록 표와 같아져서, 같은 화면에 행이 더 많이 보입니다(메뉴 권한 1919×860 창 기준 13 → 15행).
- 필수 검색필터 라벨(예: 메뉴 권한 탭의 '권한')은 antd 기본 필수 표시 '*' 가 우리 '• 점'과 겹쳐 깨졌습니다 → antd 표시를 같은 구체성의 CSS 로 덮어 **앞 점만 빨간색**으로 보입니다(`global.css`).

### 4-4. 표 높이 확보 · 설명 생략 · 조회 버튼 하나 (같은 날 추가)

- **메뉴 권한 표 머리 한 줄로**: 예전 '메뉴 권한 — L (45건) + 긴 설명' 줄과 '변경 내역 없음 … [엑셀][저장][취소]' 줄이 둘이었습니다 → `EditableGrid` 에 `title` 을 주면 **'메뉴 권한 — L (45건) · 변경 내역 없음 …… [엑셀 다운로드][저장][취소]' 한 줄**. 줄 하나만큼 표가 높아집니다(1919×860 창: 15 → 17행).
- **상세 설명 생략(모든 화면)**: 제목 옆 회색 설명(`PageFrame subtitle`)과 결과 머리 옆 설명(`ResultHeader note`)을 공통 부품이 그리지 않습니다. 화면 코드의 설명 글은 남아 있어도 보이지 않습니다(소스 주석 역할).
  - 남는 것: 빨간 경고문(`noteTone="danger"`, AS-IS ※ 안내)과 상태 안내(`PageFrame alert` — 공지사항 '읽기 전용'·'본인 글만').
- **조회 버튼 하나**: 위 버튼 줄 [조회]와 검색필터 안 [조회]가 둘 다 있던 화면(공지사항·권한관리 3탭·메뉴관리·기기정보·기기모델코드)은 `ActionBar` 가 같은 화면(탭 칸·화면 틀)에 검색필터가 있으면 [조회]를 그리지 않습니다 → **검색필터 안 [조회]만**. Ctrl+Enter 조회는 그대로. 버튼이 [조회] 하나뿐이던 줄(메뉴 권한 탭)은 줄 자체가 사라져 표가 더 높아집니다.
