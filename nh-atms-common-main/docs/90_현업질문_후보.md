# 90. 현업 질문 후보 (잠정 규칙 목록)

> nh-atms `Document/3.구현계획/22_현업확인사항_대장.md` §2 와 **같은 형식**으로 둔다(번호 · 질문 · 영향 · 미결 시 가정 · 상태). 사용자가 대장으로 옮겨 적기 쉽게.
> 이 저장소에서 nh-atms 대장은 고치지 않는다(설계 §14). 답이 오면 아래 "임시 규칙이 있는 곳" 한 곳만 고치면 되게 만들어 두었다.

> 번호: `Q-xx` = 이 저장소 질문 후보, `H-xxx` = nh-atms 대장에 이미 있는 질문, 설계 `Q6`(하이픈 없음) = 설계 §13 결정 번호(Q-01 과 같은 이야기).
