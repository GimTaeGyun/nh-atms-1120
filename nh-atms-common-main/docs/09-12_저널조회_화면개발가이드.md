# 제12부. 저널조회 (`jnal.jnalList`)

> 저널조회 화면(`jnal.jnalList`)을 빈 상태에서 처음부터 만든다고 보고 무엇을 어떤 순서로 만드는지 정리(2026-11-24).
> - 화면 설명은 탭·팝업 단위(§4), 프론트를 자세히. 가져다 쓴 공통 모듈은 §3.
> - 부록 A 는 §2 순서대로 새 파일 = 전체 소스, 기존 파일 = diff(이 화면 관련 줄만). 부록 B = SHA-512.
> - 경로 줄임: src/ = Frontend/nh-atms-web/src/, web/ = Backend/nh-atms-api/atms-web/src/main/java/kr/co/nh/atms/web/, mapper/ = Backend/nh-atms-api/atms-web/src/main/resources/mapper/

## 0. 한눈에 보기

- 자동화기기 1대의 **전자저널(영수증 인자 내용)** 을 날짜·시간·저널구분·거래결과·검색어로 찾아 목록과 롤방식(글 이어 보기)으로 보는 **조회 전용** 화면. 비유: 기기 안 영수증 두루마리를 날짜로 펼쳐 보는 돋보기.
- 근거: As-Is 저널조회 화면 스크립트·SQL·인클루드(사진·드라이브), As-Is 캡처, 피그마 저널조회 프레임(배치). **내용 = As-Is, 배치 = 피그마, 생김새 = 이 저장소 공통 부품.**

| 탭·팝업 | 테이블 | 모양(복사 견본) | 하는 일 |
|---|---|---|---|
| 화면 — 목록 보기 | `TB_JL_JNAL`(+`_CHK`) | 사용기록조회(조회 전용) | 조건 → 서버가 합친 전체 목록 → 20건씩 |
| 화면 — 롤방식 보기 | 같은 응답 | (새) 글 상자 | 행마다 인자 글을 '====' 줄로 이어 봄 |
| 팝업 `popup.jnalView` 명세표 | 목록 행 + `TB_JL_JNAL_CHK` | 사용기록 상세 팝업 + 탭 | 명세서 · 수표목록 · 저널 |

- 업무 규칙(서버 `web/jnal/service/JnalRules.java` 한 곳)
  1. 사무소·기번·저널일자 필수, 저널일자 **최대 2일**.
  2. 시작일 ≤ 오늘 − 5년 → `JNL_001`(2차 파기, 저널 2차 파기 조회 화면으로).
  3. 권한이 A·L 이 아니고 시작일 ≤ 오늘 − 3개월 → `JNL_002`(As-Is 는 사유 + 책임자 승인, 지금은 **막기만** — 잠정 Q-35).
  4. 권한 A·T·L(관리자 포함) = 전체 사무소에서 고름, 그 밖 = 내 사무소(서버도 덮어씀).
  5. IT부문(내 사무소 000080) 비관리자 = 조회조건·검색어 없음(As-Is 2020.09 개인정보 조회 제한).
  6. 테이블은 `TB_JL_JNAL` 만 — As-Is 의 ILM 분기는 2차 파기(5년) 경계라 2번에서 먼저 막힌다. ILM 은 저널 2차 파기 조회 화면 몫(Q-34).
  7. 같은 날·같은 명세표의 저널(22·33 은 00 으로 봄)은 **앞 행에 합침**(As-Is rconcat) — 인자 글 목록, 금액은 큰 값.
  8. 개인정보(계좌번호·인자 글)는 As-Is 대로 원문(사용기록에도 원문).

```text

```

## 1. 준비 — DB

- 테이블 4개는 **정본 CSV 행**으로 만든 참고 DDL(`db/ddl/TB_JL_JNAL*.sql`). 이 화면이 읽는 것은 `TB_JL_JNAL`·`TB_JL_JNAL_CHK` 2개(`_ILM` 2개는 2차 파기 조회 화면용). 개발 DB 에 있는지 `db/check/01_exists.sql`·`02_columns.sql` 로 먼저 본다.
- **행이 있어야 화면에 나온다**: 업체 수집 모듈(atms-journal)은 지금 `T_JOURNAL` 에 쓴다 → `TB_JL_JNAL` 에 행이 없으면 늘 0건(Q-39). 거래명은 `TB_CODE_DTL` 코드구분 `'01'` 행이 있어야 보인다.
- 메뉴: **메뉴관리 화면**에서 저널 대·중메뉴 아래에 소메뉴를 만들고 메뉴경로 `/jnal/jnal-list` 를 넣는다(SQL 파일 없음, 2026-11-24 사용자 결정). 권한은 권한관리 → 메뉴 권한 탭에서 '조회'.

## 4. 탭·팝업별 설명 (프론트)

### 4-1. 조회조건 (`JnalListParts.tsx` `useJnalFields`)
- 1행 사무소 · 거래결과, 2행 기번 · 저널구분, **필터 펼침** 안에 저널일자 · 조회조건 · 검색어, 저널시간(피그마 순서).
- 사무소: A·T·L(또는 관리자) = 고름(기본 내 사무소), 그 밖 = 내 사무소 고정. 기번은 사무소 종속 콤보(필수).
- 거래결과: 전체·정상·불능·취소정상·취소불능·확인요망. 저널구분: 전체·일반·수표·개국·합계·운영(As-Is 캡처 글자).
- 조회조건: 전체·수표 = 계좌번호·수표번호·명세표일련번호, 일반 = 계좌번호·명세표일련번호, 개국·합계·운영 = 명세표일련번호. 명세표는 `0001-0050`(한쪽만 써도 됨, 번호 하나 = 그 번호). 계좌는 목록에 보이는 하이픈 계좌를 붙여 넣어도 서버가 하이픈을 떼고 찾는다.
- IT부문 비관리자는 조회조건·검색어 칸이 아예 없다.

### 4-2. 목록 보기 (`JnalListColumns.tsx`)
- 11칸: 순번 · 저널일자 · 저널시간 · 저널구분(거래·개국·합계·운영) · 거래결과(운영은 빈칸) · 거래명 · 명세표 일련번호 · 계좌/카드번호/수표번호(하이픈, 수표 있으면 둘째 줄 `(수표앞8[n건])`) · 거래금액(개국·운영 빈칸) · 운영내용(운영 저널의 후인자, 잠정 Q-37) · 상세([상세] 버튼, 운영 제외).
- 위에 에코바(사무소 · 기번 · 조회일시), 결과 머리줄 오른쪽 [목록 보기 | 롤방식 보기].

### 4-3. 롤방식 보기
- 지금 결과 전체의 인자 글(전인자 + 후인자, 합친 것 모두)을 '====' 줄로 이어 붙인 읽기 전용 글 상자(남은 높이 채움, 잠정 Q-37).

### 4-4. 명세표 팝업 (`popup/JnalViewModal.tsx`)
- [명세서] 제목줄 = 거래명, 사무소 · 거래일 · 취급점_기번_일련번호 · 매체 · 개설은행(코드 그대로, Q-38) · 계좌/카드번호 · 거래금액(₩) · 영수증 글(후인자) · 빨간 안내 2줄.
- [수표목록] 탭을 열 때 `GET /api/web/jnal/checks` — 일련번호 · 수표번호.
- [저널] 인자 글 전부(고정폭). 이미지 탭은 없음(저널이미지 권한·열람기록 화면과 함께 나중).

## 5. 백엔드 요약

- `JnalController` — `selectList`·`selectChecks`, 둘 다 QRY. 사용기록 R 은 자동.
- `JnalService` — `JnalRules.normalize` → `selectList` 한 번 → `scrNm` → `merge`. 수표목록은 `normalizeKey`(같은 사무소·기간 규칙) 후 `selectChecks`.
- `JnalMapper.xml` — As-Is SQL 이식. 바뀐 점: `#{}`·`CAST(… AS CHAR(n))`, 인덱스 힌트·스키마 접두어 뺌, 수표 묶음은 조회조건이 수표번호일 때만 거름, 수표번호 검색 = 수표 묶음에 걸린 행(Q-36).

```java
    public static boolean itRestricted(String myOfc, boolean admin) {
        if (admin || trimToNull(myOfc) == null) return false;
        return IT_OFC_CODE.equals(OfficeCode.norm(myOfc));

    public static void normalize(JnalSearchDto s, String auth, boolean admin, String myOfc, String today) {
        s.setOfcCode(office(s.getOfcCode(), auth, admin, myOfc));
        s.setMcnNo(mcnNo(s.getMcnNo()));

        String from = trimToNull(s.getFromDate());
        String to = trimToNull(s.getToDate());
        if (from == null) throw new BusinessException("VAL_002", "fromDate");
        if (to == null) throw new BusinessException("VAL_002", "toDate");
        if (!isYmd(from)) throw new BusinessException("VAL_003", "fromDate");
        if (!isYmd(to)) throw new BusinessException("VAL_003", "toDate");
        long days = Dates.daysBetween(from, to);
        if (days < 1 || days > MAX_DAYS) throw new BusinessException("VAL_001", "fromDate~toDate");
        s.setFromDate(from);
        s.setToDate(to);

        destroyLimits(from, auth, admin, today);

        s.setFrTi(hhmm(s.getFromTime(), "0000", "fromTime") + "00");
        s.setToTi(hhmm(s.getToTime(), "2359", "toTime") + "59");

        String type = trimToNull(s.getJnalType());
        if (type != null && !JNAL_TYPES.contains(type)) throw new BusinessException("VAL_003", "jnalType");
        s.setJnalType(type);
        String rest = trimToNull(s.getJrnlProcRest());
        if (rest != null && !PROC_RESTS.contains(rest)) throw new BusinessException("VAL_003", "jrnlProcRest");
        s.setJrnlProcRest(rest);

        search(s, itRestricted(myOfc, admin));
    }

    /** 수표목록 키 정리 — 사무소·기번·일자 규칙은 목록과 같다(다른 사무소·파기 대상 저널을 키로 직접 읽지 못하게) */
    public static void normalizeKey(JnalCheckKey k, String auth, boolean admin, String myOfc, String today) {
        k.setOfcCode(office(k.getOfcCode(), auth, admin, myOfc));
        k.setMcnNo(mcnNo(k.getMcnNo()));
        String dt = trimToNull(k.getJnalDt());
        if (dt == null) throw new BusinessException("VAL_002", "jnalDt");
        if (!isYmd(dt)) throw new BusinessException("VAL_003", "jnalDt");
        String seq = trimToNull(k.getJnalSeqno());
        if (seq == null) throw new BusinessException("VAL_002", "jnalSeqno");
        if (seq.length() > 6) throw new BusinessException("VAL_003", "jnalSeqno");
        destroyLimits(dt, auth, admin, today);
        k.setJnalDt(dt);
        k.setJnalSeqno(seq);

    /** 2차 파기(5년) JNL_001, 1차 파기(3개월) 조회 허가 JNL_002 — 인클루드 chkLim·chkPermitINQ */
    private static void destroyLimits(String from, String auth, boolean admin, String today) {
        LocalDate t = Dates.parseYmd(today);
        String limit2 = t.minusYears(DESTROY2_YEARS).format(Dates.YMD);
        if (from.compareTo(limit2) <= 0) throw new BusinessException("JNL_001", Dates.dash10(limit2));
        String limit1 = t.minusMonths(DESTROY1_MONTHS).format(Dates.YMD);
        if (from.compareTo(limit1) <= 0 && !canSeeOld(auth, admin)) throw new BusinessException("JNL_002", Dates.dash10(limit1));
    }

    private static String office(String requested, String auth, boolean admin, String myOfc) {
        String ofc = canPickOffice(auth) || admin ? OfficeCode.norm(requested) : OfficeCode.norm(myOfc);
        if (ofc == null) throw new BusinessException("VAL_002", "ofcCode");
        return ofc;
    }

    private static String mcnNo(String v) {
        String mcn = trimToNull(v);
        if (mcn == null) throw new BusinessException("VAL_002", "mcnNo");
        if (mcn.length() > 3 || !mcn.chars().allMatch(Character::isDigit)) throw new BusinessException("VAL_003", "mcnNo");
        return "0".repeat(3 - mcn.length()) + mcn;
    }

    /** 조회조건·검색어 → schData1·2. 저널구분에 없는 조회조건은 VAL_003(As-Is 콤보 setCB_search_if) */
    private static void search(JnalSearchDto s, boolean restricted) {
        String field = upper(s.getField());
        // 공백은 늘 떼고(As-Is 는 앞뒤 trim), 계좌는 하이픈도 뗀다 — 목록에 보이는 '301-12-345678' 을 그대로 붙여 넣어도 찾게
        String raw = s.getKeyword() == null ? null : s.getKeyword().replaceAll("\\s+", "");
        String keyword = trimToNull(FIELD_ACCT.equals(field) && raw != null ? raw.replace("-", "") : raw);
        s.setSchData1(null);
        s.setSchData2(null);
        if (restricted || field == null || "ALL".equals(field) || keyword == null) {
            s.setField(null);
            s.setKeyword(null);
            return;
        }
        if (!fieldsOf(s.getJnalType()).contains(field)) throw new BusinessException("VAL_003", "field");
        s.setField(field);
        s.setKeyword(keyword);
        if (FIELD_DTLS.equals(field)) {
            Matcher m = DTLS_RANGE.matcher(keyword);
            if (!m.matches()) throw new BusinessException("VAL_003", "keyword");
            String a = pad4(m.group(1));
            String b = m.group(2) == null ? a : pad4(m.group(2));
            if (a == null && b == null) throw new BusinessException("VAL_003", "keyword");
            if (a != null && b != null && a.compareTo(b) > 0) throw new BusinessException("VAL_003", "keyword");
            s.setSchData1(a);
            s.setSchData2(b);
        } else {
            if (!KEYWORD.matcher(keyword).matches()) throw new BusinessException("VAL_003", "keyword");
            s.setSchData1(keyword);
        }
    }

    /** 저널구분별 조회조건 — 전체·33 = 계좌·수표·명세표, 22 = 계좌·명세표, 11·44·55 = 명세표 */
    public static List<String> fieldsOf(String jnalType) {
        if (jnalType == null || "33".equals(jnalType)) return List.of(FIELD_ACCT, FIELD_CHK, FIELD_DTLS);
        if ("22".equals(jnalType)) return List.of(FIELD_ACCT, FIELD_DTLS);
        return List.of(FIELD_DTLS);
    }

    /**
     * As-Is rconcat — SQL 순서대로 돌며 저널구분이 55 가 아니고 명세표 안 순번(P_RN)이 1 이 아니면 바로 앞에 남긴 행에 합친다
     * (인자 글 목록에 '전인자\n후인자', 후인자 목록에 후인자, 거래금액 = 큰 값). 앞에 남긴 행이 없으면 그대로 한 행(As-Is 는 이때 오류).
     */
    public static List<Jnal> merge(List<Jnal> rows) {
        List<Jnal> out = new ArrayList<>(rows.size());
        Jnal prev = null;
        for (Jnal r : rows) {
            String rol = nz(r.getBfoComt()) + "\n" + nz(r.getAftComt());
            String dtl = nz(r.getAftComt());
            boolean follow = !"55".equals(r.getJnalType()) && r.getPRn() != null && r.getPRn() != 1;
            if (follow && prev != null) {
                prev.getRolComts().add(rol);
                prev.getDtlComts().add(dtl);
                long a = prev.getDealAmt() == null ? 0L : prev.getDealAmt();
                long b = r.getDealAmt() == null ? 0L : r.getDealAmt();
                prev.setDealAmt(Math.max(a, b));
                continue;
            }
            r.setRolComts(new ArrayList<>(List.of(rol)));
            r.setDtlComts(new ArrayList<>(List.of(dtl)));
            out.add(r);
            prev = r;
        }
        return out;
    }

    /** 거래명 — 55 = 기기운영관리, 타행이체·타행이체조회 화면번호, 그 밖 = TB_CODE_DTL(CODE_SECT '01') 코드명 */
    public static String scrNm(String jnalType, String scrNo, String codeNm) {
        if ("55".equals(jnalType)) return "기기운영관리";
        String no = trimToNull(scrNo);
        if (no != null && TRANSFER.contains(no)) return "타행이체";
        if (no != null && TRANSFER_INQ.contains(no)) return "타행이체조회";
        return codeNm;
    }

    private static String hhmm(String v, String def, String name) {
        String t = trimToNull(v);
        if (t == null) return def;
        if (!HHMM.matcher(t).matches()) throw new BusinessException("VAL_003", name);
        return t;
    }

    private static String pad4(String v) {
        if (v == null || v.isEmpty()) return null;
        return "0".repeat(4 - v.length()) + v;
    }

    private static boolean isYmd(String v) {
        if (v.length() != 8) return false;
        try {
            Dates.parseYmd(v);
            return true;
        } catch (RuntimeException e) {
            return false;
        }
    }

    private static String first(String auth) {
        String a = trimToNull(auth);
        return a == null ? null : a.substring(0, 1).toUpperCase(Locale.ROOT);
    }

    private static String upper(String v) {
        String t = trimToNull(v);
        return t == null ? null : t.toUpperCase(Locale.ROOT);
    }

    private static String nz(String v) {
        return v == null ? "" : v;
    }

    private static String trimToNull(String v) {
        return v == null || v.trim().isEmpty() ? null : v.trim();
    }
}
```

```tsx
/** 한 번에 볼 수 있는 최대 일수 */
export const MAX_DAYS = 2;
/** IT부문 사무소코드 — 관리자가 아니면 조회조건(계좌·수표·명세표)을 쓰지 않는다(As-Is 2020.09 개인정보 조회 제한) */
export const IT_OFC_CODE = '000080';

/** 권한코드 첫 글자가 A·T·L 이면 사무소를 고른다(As-Is 'T, L 권한 유저에게 사무소 변경 권한 부여') */
export const canPickOffice = (auth?: string | null): boolean => ['A', 'T', 'L'].includes((auth ?? '').trim().slice(0, 1).toUpperCase());

export const JNAL_TYPE_OPTIONS: Option<JnalTypeCode>[] = [
  { value: '22', label: '일반' },
  { value: '33', label: '수표' },

export const PROC_REST_OPTIONS: Option<JrnlProcRestCode>[] = [
  { value: '01', label: '정상' },
  { value: '02', label: '불능' },
  { value: '97', label: '취소정상' },
  { value: '98', label: '취소불능' },

const FIELD_LABELS: Record<JnalField, string> = { ACCT: '계좌번호', CHK: '수표번호', DTLS: '명세표일련번호' };
const fieldOpt = (f: JnalField): Option => ({ value: f, label: FIELD_LABELS[f] });
const FIELD_OPTIONS: Option[] = [fieldOpt('ACCT'), fieldOpt('CHK'), fieldOpt('DTLS')];

/** 저널구분별 조회조건 — 전체·수표 = 계좌·수표·명세표, 일반 = 계좌·명세표, 개국·합계·운영 = 명세표(As-Is setCB_search_if) */
export const fieldOptionsOf = (jnalType: unknown): Option[] => {
  if (!jnalType || jnalType === '33') return FIELD_OPTIONS;
  if (jnalType === '22') return [fieldOpt('ACCT'), fieldOpt('DTLS')];
  return [fieldOpt('DTLS')];
};

/** 저널구분 표시 — 00·22·33 거래, 11 개국, 44 합계, 55 운영 */
export const jnalTypeText = (t?: string | null): string => {
  switch (t) {
    case '00':
    case '22':
    case '33':
      return '거래';
    case '11':
      return '개국';
    case '44':
      return '합계';
    case '55':
      return '운영';
    default:
      return '';
  }
};

const PROC_REST_TEXT: Record<string, string> = { '01': '정상', '02': '불능', '97': '취소정상', '98': '취소불능', '99': '확인요망', '77': '고객조작취소' };
/** 거래결과 표시 — 운영(55) 저널은 빈칸 */
export const procRestText = (r: Pick<Jnal, 'jnalType' | 'jrnlProcRest'>): string => (r.jnalType === '55' ? '' : PROC_REST_TEXT[r.jrnlProcRest ?? ''] ?? '');

/** 계좌/카드번호/수표번호 두 줄 — 계좌 하이픈, 수표가 있으면 둘째 줄 '(수표앞8[n건])' */
export const acctLines = (r: Pick<Jnal, 'acctNo' | 'estbBankCode' | 'chkCnt' | 'chkNos'>): string[] => [
  r.acctNo ? fmtAcctNo(r.acctNo, r.estbBankCode) : '',
  r.chkCnt && r.chkCnt > 0 ? `(${(r.chkNos ?? '').slice(0, 8)}[${r.chkCnt}건])` : '',
];

/** 거래금액 — 개국(11)·운영(55)은 빈칸 */
export const amountText = (r: Pick<Jnal, 'jnalType' | 'dealAmt'>): string => (r.jnalType === '11' || r.jnalType === '55' ? '' : fmtAmount(r.dealAmt, { dash: '' }));

/** 운영내용 — 운영(55) 저널의 후인자(잠정 Q-37: As-Is 원문 줄이 없어 후인자 그대로) */
export const opText = (r: Pick<Jnal, 'jnalType' | 'aftComt'>): string => (r.jnalType === '55' ? (r.aftComt ?? '') : '');

/** 상세 팝업을 열 수 있는 행(운영 저널 제외) */
export const hasDetail = (r: Pick<Jnal, 'jnalType'>): boolean => r.jnalType !== '55';

/** 롤방식 글 — 행마다 인자 글(합친 것 모두)을 구분선으로 이어 붙인다(잠정 Q-37) */
export const ROLL_SEPARATOR = `\n\n${'='.repeat(48)}\n\n`;
export const rollText = (rows: Pick<Jnal, 'rolComts'>[]): string => rows.flatMap((r) => r.rolComts).join(ROLL_SEPARATOR);

/* ---------- 2. 조회조건 (모두 공통 필드, 배치 = 피그마) ---------- */
/**
 * 1행 사무소·거래결과, 2행 기번·저널구분, 상세 필터 = 저널일자(최대 2일)·저널시간(시 단위)·조회조건·검색어.
 * canPick = 권한 A·T·L(또는 관리자) → 사무소를 고름, 아니면 내 사무소 고정. itRestricted = 조회조건·검색어 칸 없음.
 */
export const useJnalFields = (canPick: boolean, myOfc: string, itRestricted: boolean): SearchField[] =>
  useMemo(
    () => [
      canPick ? officeField({ defaultValue: myOfc || undefined }) : officeField({ disabled: true, defaultValue: myOfc }),
      optionField('jrnlProcRest', '거래결과', PROC_REST_OPTIONS),
      mcnField({ required: true, newRow: true }),
      optionField('jnalType', '저널구분', JNAL_TYPE_OPTIONS),
      rangeField({ label: '저널일자', maxDays: MAX_DAYS, advanced: true, newRow: true }),
      ...(itRestricted
        ? []
        : keywordTypeFields({
            options: FIELD_OPTIONS,
            typeLabel: '조회조건',
            optionsBy: { watch: 'jnalType', map: fieldOptionsOf },
            keywordPlaceholder: '계좌·수표 = 일부, 명세표 = 0001-0050',
          }).map((f) => ({ ...f, advanced: true }))),
      timeRangeField({ label: '저널시간', hourly: true, advanced: true, newRow: true }),
    ],
    [canPick, myOfc, itRestricted],
  );

/* ---------- 3. 조건값 → API 파라미터 ---------- */
export const toJnalParams = (v: Record<string, unknown>): JnalSearch => {
  const { fromDate, toDate } = ymdRange(v.period);
  const { fromTime, toTime } = timeParams(v.time);
  const { field, keyword } = keywordTypeOf<JnalField>(v);
  return compactParams<JnalSearch>({
    ofcCode: String(v.ofcCode ?? ''),
    mcnNo: String(v.mcnNo ?? ''),
    fromDate,
    toDate,
    fromTime,
    toTime,
    jnalType: allToUndef(v.jnalType) as JnalTypeCode | undefined,
    jrnlProcRest: allToUndef(v.jrnlProcRest) as JrnlProcRestCode | undefined,
    field,
    keyword,
  }) as JnalSearch;
};

/* ---------- 4. 명세서(상세 팝업 첫 탭) 항목 — 피그마 팝업 순서 ---------- */
export const slipItems = (r: Jnal, officeLabel: string): DetailItem[] => [
  { label: '사무소', value: officeLabel || fmtOffice(r.ofcCode), span: 2 },
  { label: '거래일', value: fmtDate(r.dealDate) },
  { label: '취급점_기번_일련번호', value: <span className="mono">{`${r.ofcCode}_${r.mcnNo}_${r.dtlsSeqno ?? ''}`}</span> },
  { label: '매체', value: r.mdnType },
  { label: '개설은행', value: r.estbBankCode },
  { label: '계좌/카드번호', value: r.acctNo ? fmtAcctNo(r.acctNo, r.estbBankCode) : undefined, span: 2 },
  { label: '거래금액', value: amountText(r) ? `₩ ${amountText(r)}` : undefined, span: 2 },
];
```
